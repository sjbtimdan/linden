## Full description (max 4000 chars)

Linden 是一款快速、私密的記帳應用，幫你掌控每一筆支出——無帳號、無廣告、無雲端。

一處記錄所有
幾秒內記錄支出、收入和轉帳。按戶口和分類整理記錄，清楚看到錢花在哪裡。

多貨幣設計
支援 CHF、CNY、EUR、GBP、HKD、IDR、INR、JPY、SGD 和 USD 戶口。Linden 以最新匯率換算總額，讓餘額始終一目了然。

快速智能記帳
• 內置精確計算機，邊輸邊算
• 根據歷史記錄智能提示描述和欄位
• 戶口之間轉帳，跨貨幣亦只需幾步

看懂你的開支
• 按記錄、戶口或分類查看帳目
• 週期導覽，回看任何一週、一月或一年
• 搜尋與篩選，隨時找到任何記錄
• 期末餘額，未來記錄的處理方式一目了然

你的資料屬於你
Linden 將所有資料保存在你的裝置本地。無追蹤、無廣告。應用程式崩潰時會發送匿名崩潰報告以修正問題——絕不包含你的財務資料。隨時將完整記錄備份到檔案並還原，或匯入現有資料。

Linden 是個人理財記帳工具，不是銀行，亦永遠不會連接你的銀行戶口。
